# Documentation Archive

Files in this directory are retained for historical context and are **not current authority**.

Before moving a document here:

1. review it for active references and unique operational instructions;
2. identify the canonical replacement where one exists;
3. add a banner stating that it is archived and non-canonical;
4. move it in a dedicated commit so Git history remains easy to follow;
5. update `docs/governance/CANONICAL_DOCUMENT_REGISTER.md`.

Do not place source evidence, migrations, runtime audit records, or retention-controlled operational data here merely to simplify the repository tree.
